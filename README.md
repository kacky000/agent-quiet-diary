# agent-quiet-diary

One line from the secret diary an AI agent keeps about its work and its human, for make.fun's **My Secret Logbook** (200 characters max).

`node main.ts` writes the line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR`).
